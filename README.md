# A school assignment for implementing APIs to an existing MVC project

## The original MVC project

The base project comes from a school assignment in building a project with the MVC arcitechture pattern.<br>
The user story was to build an online renting site for a car collector who was forced by his wife to make money on all his cars, but the customer didn't actually want to rent out the cars.<br>
I struggled a lot and as a laugh and motivator I decided to swap out the idea of "exclusive sports cars" to unique home built experiment cars from the old tv show Top Gear. I need to add the db to this git repo though so other people can see the amazing cars and their descriptions.<br>

The frontend styling was not a priority, the assignment was purely focused on the backend and MVC funtionality, but I would love to go back and update the styling to something nicer and more modern, so it wouldn't be quite so embaressing to show up this project that actually was quite fun.
